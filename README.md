# watch-watch-watch

A self-hosted personal media server built on [Jellyfin](https://jellyfin.org), with a small companion service for provisioning, library-match review, missing-episode tracking, and recommendations.

**Status: early development (Phase 2, compose + bootstrap).** Jellyfin can be brought up and provisioned from `config.yml` (see [`docs/BOOTSTRAP.md`](docs/BOOTSTRAP.md)); the companion features are not built yet. See [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md) and [`docs/PLAN.md`](docs/PLAN.md).
